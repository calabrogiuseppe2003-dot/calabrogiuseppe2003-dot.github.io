# Giuseppe Calabrò — personal academic website

A minimal, text-first academic homepage built with plain HTML and CSS.

## Local preview
Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Before publishing
1. Replace `YOUR-USERNAME` in `index.html` with your GitHub username.
2. Put your current CV PDF at `assets/cv.pdf`.
3. Optionally add a portrait at `assets/images/profile.jpg` and uncomment the image element in `index.html`.
4. Check the PhD institution/title and update the text if you want to name the university or research group.
5. Update the email address if you no longer use the Oxford address.

## Publish with GitHub Pages
For a personal site, create a public repository named `YOUR-USERNAME.github.io`, then push these files to its `main` branch. In Settings > Pages, select deployment from `main` and `/ (root)`.
